# GrokShitSnake

A shitty ass web browser version of snake. Proudly presented to you by Trashbird.

Arcade Snake in the browser. Steer with the keyboard, on-screen pad, or swipe. Eat the red pellets. Walls and your own tail end the run. Best score stays in this browser.

The repo was renamed from `GrokShitSnake-0.1` to `GrokShitSnake`. The old GitHub Pages URL followed the rename. **Nothing was deleted** — every shipped version is frozen under `/play/`.

## Play locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43180](http://127.0.0.1:43180). Frozen copies are at `/play/`.

## Controls

- **Enter** or **GO** to start / restart
- **Arrows** or **WASD** to turn
- **Space** to pause
- On a phone, swipe the board or use the pad
- Sound starts on the first GO / key / tap

## Build

```bash
npm run build
npm run preview
```

Pushing `main` deploys a static build to GitHub Pages, including every frozen version under `play/`.
